Reproducing#

The Ballista numbers come from the tpch runner in this repository. The Spark, Spark + Comet, and Trino numbers were collected with a benchmark harness that is not in this repository yet. We are working on adding scripts so that anyone can reproduce all of these results. See the per-engine pages below for the commands and settings.

How the cluster was set up and how each engine was configured:

Recording a new result set#

  • Pin the exact commit the numbers came from, not a branch name.

  • Replace the version, environment, config, and results tables together — a row that mixes numbers from different commits silently misattributes a regression.

  • Prefer a single continuous suite run: a long-lived executor deep into a suite is not in the same state as a freshly started one.

  • Report FAIL for a query that ran but did not produce an answer, and OOM when the failure is a known memory exhaustion. See the tracker for open issues found by benchmarking: #1359, #2025, #2063.
