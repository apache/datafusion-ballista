Apache DataFusion Ballista 55.0.0 Changelog#

This release consists of 322 commits from 25 contributors. See credits at the end of this changelog for more information.

Fixed bugs:

  • fix(scheduler): persist terminal job state before cache eviction #2037 (phillipleblanc)

  • fix: spill sort shuffle writer when the memory pool rejects a reservation grow #2061 (andygrove)

  • fix: enable the executor client pool by default #2069 (andygrove)

  • fix: map a task’s partition through UnionExec when restricting file scans #2070 (andygrove)

  • fix: keep EmptyExec partition count intact across stage serialization [AQE] #2062 (andygrove)

  • fix: remove the static planner SortMergeJoinExec broadcast conversion #2072 (andygrove)

  • fix: propagate sort shuffle memory_limit_per_task_bytes to executors #2090 (andygrove)

  • fix: executor hanging on ctrl+c #2107 (sandugood)

  • fix: Various fixes for AQE join selection #2124 (andygrove)

  • fix: Enable more TPC-DS queries #2064 (andygrove)

  • fix(executor): keep heartbeating while all task slots are busy #2159 (andygrove)

  • fix: unskip five TPC-DS queries by rewriting generator column names #2183 (andygrove)

  • fix: stop every task running every union branch at low partition counts #2186 (andygrove)

  • fix(scheduler): execute null-aware anti joins in one task #2188 (phillipleblanc)

  • fix(scheduler): keep GROUP BY-less aggregates when propagating empty stages #2194 (andygrove)

  • fix(scheduler): harden PropagateEmptyExecRule against grouping sets, embedded projections, and dropped exchange partitioning #2200 (andygrove)
